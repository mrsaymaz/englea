# v6.7 güncellemesi — Terminal gerekmez

1. `english-league-v6-7-netlify.zip` dosyasını indirip açın.
2. Netlify'ye bağlı mevcut GitHub deponuzu açın. `public`, `netlify` ve `netlify.toml` dosyalarının bulunduğu ana dosya listesine gidin.
3. **Add file → Upload files** seçeneğini kullanın. Açtığınız `english-league-v6-7-netlify` klasörünün **içindekileri** yükleyin. Dış klasörü veya ZIP'i yüklemeyin.
4. Değişiklikleri Netlify'nin yayımladığı dala kaydedin (**Commit changes**). Netlify'deki yeni dağıtımın tamamlanmasını bekleyin.
5. Siteyi gizli/özel bir tarayıcı penceresinde açın. Başlangıç ekranında **Animated Evolution · v6.7** yazdığını kontrol edin.
6. Yeni avatar çizimleri için **Animated** modunu seçin. Tahtayı ve telefonun uzaktan kumanda sayfasını yenileyin.

**Tam paketi yükleyin.** Bu güncellemede `public/index.html`, `public/animated-mode.js`, `public/animated-mode.css`, `public/raid-motion.js` ve `public/assets/animated/` birlikte gereklidir. Yalnızca index.html yüklemek yeterli değildir.

Netlify publish klasörü: `public`. Functions klasörü: `netlify/functions`.
Cloudflare ortam değişkenlerinizi yeniden oluşturmanız veya yeni bir Netlify Function eklemeniz gerekmiyor.

Kontrol: Dört takım Level 10 olduğunda ve Class Mission tamamlandığında VIXAR savaşını başlatın. Önce mühürler kırılmalı; VIXAR %10 canda son saldırısını yapmalı; dört takım Knocked Out durumuna düşmeli; dört renkli hüzme Guardian'ı çağırmalı; son vuruşla takımların canı tamamen dolmalı.

Eski sürüm görünüyorsa GitHub'daki `public/index.html` dosyasının ilk satırlarında v6.7 yazdığını ve Netlify'nin doğru dal/commit'i yayımladığını kontrol edin.
