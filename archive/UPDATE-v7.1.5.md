# Update your existing Netlify site to v7.1.5

1. Extract this ZIP.
2. Replace the existing site source with the complete updated `public` folder and the included project files.
3. Deploy using your normal Netlify process.
4. Reload both the smartboard and phone. The opening screen should show **Animated Evolution · v7.1.5**.

The Google Apps Script, TURN function and Netlify environment settings are unchanged. No Apps Script redeployment is needed.
